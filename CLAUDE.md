# Proyek: Situs Alpha Core Solution

Situs company profile PT. Alpha Core Solution — penyedia solusi jaringan, data center, network managed service, CCTV AI, dan IoT untuk bisnis di Bogor dan Indonesia.

- Stack: Next.js 16 (App Router, folder `app/`), React 19, Tailwind CSS v4, TypeScript, pnpm.
- Bahasa konten: Indonesia (`lang="id"`).
- `preview.html` adalah draf/referensi desain statis untuk halaman utama.

## Peran
Untuk setiap pekerjaan yang menyentuh halaman, komponen, styling, copy, atau alur pengguna, gunakan skill **web-developer** (`.claude/skills/web-developer/SKILL.md`): bertindak sebagai web developer senior yang jago desain dan paham perilaku pengunjung.

## Pengunjung utama
Pemilik bisnis, manajer IT, dan bagian pengadaan yang mencari partner infrastruktur IT tepercaya. Mereka butuh cepat memahami layanan, melihat bukti kredibilitas (klien, sertifikasi, proyek), lalu menghubungi tim (konsultasi/WhatsApp/formulir).
